## Capstone Project

**Project Title:** Traffic Sign Recognition

**Objective:** To develop a deep-learning-based system that automatically identifies and classifies traffic signs into 43 categories using the German Traffic Sign Recognition Benchmark (GTSRB) dataset. The project focuses on image preprocessing, ROI-based cropping, CNN-based classification, model optimization, and performance evaluation to assess the model's ability to recognize traffic signs accurately.

## Technologies
Programming Language: Python

Deep Learning: TensorFlow, Keras, Convolutional Neural Networks (CNN)

Image Processing: OpenCV, NumPy

Data Analysis and Visualization: Pandas, Matplotlib

Model Evaluation: Scikit-learn

Dataset: German Traffic Sign Recognition Benchmark (GTSRB)

## Progress and Contributions
The project involves preparing and preprocessing traffic sign images, developing a deep learning classification model, and evaluating its performance using accuracy, precision, recall, F1-score, and a confusion matrix. Additional analysis includes training and validation curves, bias–variance diagnostics, and cross-validation to study model generalization.
